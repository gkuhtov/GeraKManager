## 🧭 О проекте

**GeraKStore Manager** — настольный инструмент для обслуживания каталога GeraKStore. Он объединяет подготовку сведений о приложениях, обработку IPA, работу с выпусками GitHub и формирование данных, которые затем использует каталог.

## ✨ Основные задачи

- 📦 Добавление и редактирование записей приложений.
- 🧾 Чтение метаданных и обработка файлов IPA.
- 🖼️ Подготовка значков и сопутствующих ресурсов.
- 🚀 Работа с выпусками GitHub и файлами приложений.
- 📄 Формирование манифестов и данных репозитория.
- 🔄 Синхронизация сведений с GeraKStore.

Фактический набор возможностей определяется исходным кодом текущей версии. Это описание не заменяет инструкции в интерфейсе программы.

## 🧱 Структура проекта

| Путь | Назначение |
|---|---|
| `main.py` | Точка запуска приложения |
| `core/` | Обработка данных, синхронизация, GitHub и генерация файлов |
| `ui/` | Окна и элементы интерфейса |
| `data/` | Данные приложений и настройки |
| `assets/` | Значки и визуальные ресурсы |
| `docs/MASTER_PLAN.md` | План развития проекта |
| `requirements.txt` | Зависимости Python |
| `Info.plist` | Метаданные, используемые в проекте |

## 🛠️ Технологии

- Python
- GitHub API и механизмы публикации выпусков
- Форматы JSON и plist
- Графический интерфейс, реализованный в каталоге `ui/`

## ▶️ Подготовка к запуску

1. Установите подходящую версию Python.
2. Установите зависимости из `requirements.txt` в отдельное виртуальное окружение.
3. Проверьте настройки в каталоге `data/` и доступы, необходимые для публикации.
4. Запускайте приложение предусмотренным проектом способом; точку входа следует сверять с `main.py`.

Не публикуйте токены доступа и другие секреты в репозитории. Перед изменением параметров синхронизации проверьте целевой репозиторий и формат данных.
